# SWYNEX Task 2 – Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the cleaned Online Retail dataset from Task 1 as part of the SWYNEX internship.

## Objective
To explore the dataset, calculate important statistics, identify patterns and anomalies, and present useful insights using Microsoft Excel.

## Dataset Details
- Dataset: Online Retail
- Source: UCI Online Retail Dataset
- Records analysed: 19,549
- Original columns: 8
- Tool used: Microsoft Excel 2013

## Analysis Performed
- Calculated total sales, total quantity, average unit price, minimum unit price, and maximum unit price.
- Analysed country-wise sales and quantity using PivotTables and charts.
- Identified the top 10 sales items.
- Reviewed missing CustomerID values and negative quantities.
- Examined the available date range.

## Key Insights
1. The United Kingdom recorded the highest sales, totalling 309,232.88.
2. REGENCY CAKESTAND 3 TIER was the highest-selling item in the Top 10 analysis, with sales of 12,780.93.
3. The Top 10 sales items recorded combined sales of 64,214.05.
4. The dataset contained 261 records with negative quantities, which may represent returns or cancellations.
5. CustomerID was missing in 6,517 records, limiting customer-level analysis.
6. All available records were from December 2010, so month-to-month comparisons were not possible.

## Summary Statistics
- Total Sales: 338,412.84
- Total Quantity: 156,114
- Average Unit Price: 7.78
- Maximum Unit Price: 13,541.33
- Minimum Unit Price: 0.03

## Tools Used
- Microsoft Excel 2013
- PivotTables
- Bar and column charts
- GitHub

## Conclusion
The analysis helped identify sales concentration by country, leading sales items, and data quality limitations. The findings provide a useful overview of the available retail data.
